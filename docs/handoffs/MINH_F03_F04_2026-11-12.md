## Đối chiếu DTO thật

| DTO/source Java | Khác biệt đã xử lý |
|---|---|
| CaseSummaryResponse | Chỉ id,organizationId,internalTitle,status,priority,version,createdAt. Không bắt creator/needsCount/alias/area và không bịa giá trị |
| CaseDetailResponse.Creator | `fullName`→displayName cho view |
| CaseDetailResponse | public fields nullable; needs/consent/evidence và timestamps thật. Không bịa campaign/goods/dispute projections |
| Review/chain trên detail | Không có reviewHistory/blockchainStatus. Hiện lịch sử chưa được cung cấp và chain UNKNOWN; không suy từ VERIFIED thành confirmed |
| PatchCaseRequest | expectedVersion>=0; whitelist text/priority/needs; null/omitted giữ nguyên, empty public text để clear |
| ResubmitCaseRequest | expectedVersion; backend kiểm tra revision sau request-changes. Khi detail thiếu history, cho server kiểm tra, tránh khóa vĩnh viễn sau reload |
| DecisionRequest | expectedVersion>=0, reason<=2000,1–10 UUID reviewedEvidenceVersionIds |
| DecisionResponse | verificationId,caseId,decision,caseStatus,caseVersion,reviewerId,reviewedAt,auditEventId,blockchainStatus. Verify PENDING_ON_CHAIN; local decision NOT_APPLICABLE |
| EvidenceFixtureResponse | key,title,mimeType,byteSize,sha256; adapter title→label. Không file path/private URL |
