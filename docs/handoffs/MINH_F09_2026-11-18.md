## Lệnh tái hiện

Chuẩn bị Java 21, Node, PostgreSQL test riêng, cài frontend theo lockfile và Chromium như workflow `.github/workflows/f07-real-e2e.yml`. Đặt `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, `AIDBRIDGE_TEST_DATABASE_URL/USERNAME/PASSWORD`, `PGHOST/PGPORT/PGDATABASE/PGUSER/PGPASSWORD` trỏ DB test; đặt `AIDBRIDGE_F07_REAL_E2E=true`, `BLOCKCHAIN_ENABLED=false`, `NEXT_PUBLIC_API_MODE=real`, `CI=true`, `PLAYWRIGHT_JUNIT_OUTPUT_FILE=test-results/f07-real.junit.xml`.

```text
cd frontend
npm test
npm run typecheck
cd ../backend/aidbridge-backend
./mvnw -B -ntp -Dtest=CommitmentRequestValidationTest,CancellationRequestValidationTest -Dit.test=DonorUiE2EIT verify
```

Lượt Windows local dùng Maven offline/cache có sẵn, thêm `-DargLine=-javaagent:<mockito-core.jar>` để tránh self-attach và `-Dfailsafe.timeout=600`. Host tự build Next, khởi động backend/frontend, rồi chạy `node node_modules/@playwright/test/cli.js test --project=donor-real --reporter=list,junit`. Không cần chạy E2E trực tiếp vào DB demo.
